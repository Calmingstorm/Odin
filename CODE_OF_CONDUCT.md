# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, keep discussions about the work, and take disagreements to evidence rather than volume. Harassment, personal attacks, and publishing others' private information are not tolerated.

Reports go to the maintainer via the contact on the [GitHub profile](https://github.com/Calmingstorm). Reports are handled privately and in confidence.
