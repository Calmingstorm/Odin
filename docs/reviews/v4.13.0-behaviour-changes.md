## Payload boundary details

The command budget is 128 KiB minus an 8 KiB margin (122,880 bytes), reserving
space for the terminating NUL and transport/shell wrapping. This is a
conservative per-argument budget, not a new shared transport guarantee.
The old builder is kept intact; compression is considered only after measuring
its UTF-8 command bytes. The compressed form retains private temporary files,
cleanup traps, error checks and the exact engine/plan contents.

Tests pin the old command against a frozen master builder, exercise local
real-engine application above the old argv ceiling, mock the remote dispatch
boundary without connecting, and test exact/one-byte-over boundaries for both
forms. The incompressible refusal fixture reduces the command budget because
the unchanged 48 KiB grammar cap ordinarily keeps compressed random ASCII plans
below the production command budget. No production parser limit is relaxed.
