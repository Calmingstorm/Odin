# Generated references

- [API reference](api.md): offline inventory of registered HTTP routes.
- [Static built-in tool catalog](tools.md): registry-backed definitions only.

The static catalog does **not** enumerate dynamically registered native computer
tools: `computer_session`, `computer_observe`, and `computer_act`. See the
[computer-use operator reference](../computer-use/OPERATOR.md) for their workflow,
capability limits, consent requirements and safety boundaries. Catalog counts do
not assert that these tools are absent from a configured running installation.
